Get Started How It Works

A real proof graph

Load the graph and select a dot to read a lemma’s statement and proof. Follow a line downward to a lemma it cites, or upward to one that uses it. Suspended lemmas are left out by default. In an export made with --suspended, they appear as red dots ringed in red: you can still read them, but a new proof cannot rely on them.
